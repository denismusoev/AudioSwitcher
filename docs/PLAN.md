# AudioSwitcher — краткий план

Цель: портативное приложение для Windows 10/11 x64 с выбором аудиовыхода и главного монитора.

## Управление программами 1.4.0

Согласованный проект и этапы: [2026-09-18-program-management.md](superpowers/plans/2026-09-18-program-management.md).

- Третий раздел «Программы»: отдельные «Запущенные» и «Для запуска».
- Проверка принадлежности окна/экземпляра процесса, перенос на текущий главный экран и завершение одного процесса с подтверждением.
- Ручной каталог EXE/.lnk/.url в профиле пользователя, редактирование, безопасное сохранение и сброс с резервной копией.
- X — переключение списков, B/Esc — возврат из панелей; удержание A/Enter не подтверждает следующий экран.
- Собственная оконная программа для интеграционных проверок зависания, нескольких окон/экземпляров, запуска и переноса; проверка игровых ограничений требует конкретной игры.

- [x] C# / .NET 10 / WPF, без сторонних библиотек. Самодостаточный EXE.
- [x] Два списка устройств, окно поверх обычных окон, русский интерфейс.
- [x] Windows Core Audio: активные выходы, установка устройства по умолчанию для трёх ролей.
- [x] Мониторы: перенос начала координат на выбранный экран с сохранением взаимного расположения; проверка режимов перед применением, восстановление при ошибке.
- [x] XInput: крестовина и левый стик, A — применить, B — закрыть, LB/RB — раздел. Клавиатура и мышь также работают. Esc закрывает процесс.
- [x] Автоматические проверки координат мониторов и обработки удержания кнопок; проверка перечисления устройств и запуска окна.
- [x] Сборка portable EXE и инструкция. Настройки системы меняются только при подтверждении пользователем.

Ограничения: XInput-геймпады; эксклюзивный полноэкранный режим игр может перекрывать обычные окна. Аудиопереключение использует распространённый, но недокументированный IPolicyConfig. Программы с собственным выбранным выходом могут не следовать системному устройству.
