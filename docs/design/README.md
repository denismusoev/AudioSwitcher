# Макеты дизайна

Сохранено 18 сентября 2026 года.

## Упрощённый объединённый вариант

- `ps5-refined.html` — основа первого варианта с верхними вкладками из второго, нейтральной палитрой и одной строкой статуса вместо подключения геймпада.
- `ps5-refined-preview.png` — изображение новой версии.
- `ps5-refined-source.html` — редактируемый исходный фрагмент.

В новом макете Enter или двойной клик показывают переключение, затем результат; для мониторов также отображается сохранение. Это локальная имитация. Ориентир для оформления — официальный снимок меню Audio Focus в [PlayStation Blog](https://blog.playstation.com/2025/04/23/new-ps5-system-software-update-features-audio-focus-and-the-return-of-the-classic-console-ui-customizations/).

## Первые три варианта

- `ps5-options.html` — страница с тремя интерактивными вариантами. Откройте двойным кликом в браузере. Вкладки переключают раздел, нажатие на устройство выделяет его, Enter или двойной клик имитирует применение.
- `ps5-options-preview.png` — изображение всех трёх вариантов для быстрого просмотра, в том числе без интернета.
- `ps5-options-source.html` — исходный редактируемый фрагмент для последующих изменений и отображения в беседе.

Варианты: 01 «Центр управления», 02 «Карточки устройств», 03 «Список настроек». Рекомендованный вариант — 01. Макеты сохраняют подсказки Xbox/XInput, без названия приложения, верхних кнопок и полосы прокрутки.

Макеты не меняют настройки Windows. В самостоятельной странице иконки загружаются через интернет; элементы управления и выбор устройств работают локально. Панель настройки дизайна доступна только при просмотре исходного фрагмента в Codex.
