# Полная оболочка AudioSwitcher в стиле PS5

Денис, здесь сохранён макет до упрощения в компактную утилиту. Исходник скопирован без изменений 18 сентября 2026 года.

- `index.html` — самостоятельная страница. Откройте двойным щелчком в браузере. Библиотека иконок встроена, поэтому основной интерфейс воспроизводится без интернета. Дополнительные подсказки при наведении используют внешние библиотеки.
- `source.html` — исходный фрагмент для повторного отображения через Visualize и дальнейшего редактирования. Настройки композиции доступны в панели дизайна Visualize.
- `home.png`, `control-center.png`, `settings.png` — снимки главного экрана, центра управления и настроек.

Нижние иконки открывают панели звука, мониторов и программ. Шестерёнка открывает настройки. Плитка выбирает элемент; Enter, двойной щелчок или кнопка действия имитируют применение. Три композиции используют один исходник. Размер страницы зависит от окна браузера.

Все устройства и программы — демонстрационные данные. Макет не меняет настройки Windows и не запускает реальные программы. Самостоятельная страница сохраняет выбор локально в браузере; для возврата к исходному виду очистите данные этой страницы.

Для воспроизведения через Codex передайте `source.html` плагину Visualize. Для просмотра без Codex используйте `index.html`.
