# Компактная ТВ-версия AudioSwitcher

Дата: 19 сентября 2026 года.

## Что показано

Макеты сохраняют визуальный язык текущего приложения: графитовый радиальный фон, Segoe UI, нейтральную серую палитру, тонкие разделители, небольшие скругления и белый контур фокуса. Для телевизора меняется не стиль, а структура и масштаб взаимодействия.

- `01-control.png` — стартовый экран с двумя ежедневными действиями.
- `02-running.png` — список открытых приложений.
- `03-launch.png` — пользовательский каталог запуска.
- `04-audio-picker.png` — локальный overlay выбора аудиоустройства.
- `05-settings.png` — настройки как редкий overlay, а не постоянная вкладка.
- `06-display-picker.png` — выбор главного монитора.
- `07-window-picker.png` — выбор конкретного окна приложения.
- `08-editor.png` — редактор записи каталога.
- `09-confirm-close.png` — подтверждение закрытия приложения с безопасным фокусом на отмене.
- `10-confirm-delete.png` — подтверждение удаления только записи каталога.
- `11-error.png` — понятная ошибка с возможностью повторить действие.
- `12-empty-catalogue.png` — пустое состояние каталога с явным следующим шагом.
- `00-current-analysis.png` — сводный лист снимков и выводов по текущему интерфейсу.
- `overview.png` — все 12 состояний ТВ-концепта на одном листе.
- `current-interface/` — WPF-снимки текущей реализации на тестовых данных.
- `mockup.html` — воспроизводимый источник всех пяти макетов; экран задаётся query-параметром `screen`.
- `current-analysis.html` — воспроизводимый источник листа анализа.
- `overview.html` — воспроизводимый источник сводного листа.

## Ключевые решения

- Три корневых раздела: «Управление», «Запущенные», «Для запуска».
- Настройки открываются по Menu/Start и не занимают место в основной навигации.
- Компактная центральная поверхность 1220×760 внутри ТВ-кадра 1920×1080.
- Весь ряд — единая цель фокуса; отдельные мелкие кнопки внутри строки отсутствуют.
- Фокус и системное состояние разделены: белая рамка означает действие по A, подписи «Активно»/«Главный» обозначают фактическое состояние.
- Внизу показаны только доступные в текущем контексте команды.
- Максимальная глубина сценария: корневой экран → дочерний экран → одно подтверждение.

## Как открыть

Откройте `mockup.html` в браузере. Доступные значения параметра `screen`: `control`, `running`, `launch`, `picker`, `settings`, `display`, `window`, `editor`, `confirm-close`, `confirm-delete`, `error`, `empty`.
