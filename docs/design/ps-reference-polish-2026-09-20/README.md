# PS reference polish — интерактивный макет

Макет уточняет визуальный язык AudioSwitcher по трём предоставленным референсам: полноэкранная двухколоночная композиция, мягкий графитовый фон, тонкие линии, лёгкая типографика и правая панель выбора.

Откройте `mockup.html` в браузере.

## Управление

- `↑` / `↓` — перемещение фокуса;
- `Enter` или `A` — выполнить действие;
- `Q` / `E` — предыдущий или следующий раздел;
- `S` — настройки;
- `Esc` или `B` — назад;
- мышь поддерживается для всех видимых элементов.

Макет предназначен для проверки направления до переноса визуальных решений в WPF. Оптимальный формат просмотра — 16:9.
