# AudioSwitcher в стиле PS5 Settings

Интерактивный HTML-макет, собранный по реальным снимкам раздела настроек PS5, предоставленным Денисом 19 сентября 2026 года.

## Экраны

- `?screen=control` — звук, главный монитор и быстрые настройки.
- `?screen=running` — запущенные приложения.
- `?screen=launch` — каталог программ.
- `?screen=settings` — редкие параметры поведения.

## Управление

- Мышь: выбор раздела, строки и значения.
- `←` / `→`: переключение разделов.
- `↑` / `↓`: выбор строки.
- `Enter` или `A`: выполнить действие.
- `Escape` или `B`: закрыть список выбора.

Макет не меняет системные настройки и не запускает программы.
