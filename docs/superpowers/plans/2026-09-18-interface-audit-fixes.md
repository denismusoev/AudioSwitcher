# Исправления интерфейса по аудиту

Денис подтвердил реализацию рекомендаций из двух отчётов 18 сентября.

## Цель и ограничения

Устранить наложение интерфейсов и сохранить быстрый выбор мышью, клавиатурой и геймпадом. WPF/.NET 10, без новых пакетов. Не возвращать отдельные кнопки закрытия главного окна и применения устройств. Не менять реальные настройки устройств при автоматической проверке.
