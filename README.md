# AudioSwitcher

Портативная программа для Windows 10/11 x64: выбор аудиовыхода и главного монитора, перемещение и завершение приложений, запуск программ из своего каталога. Не требует установки .NET, установщика или прав администратора.

## Запуск

Запустите `AudioSwitcher.exe` из `artifacts/portable/win-x64` либо распакуйте `artifacts/AudioSwitcher-win-x64.zip`. Окно открывается поверх обычных окон. Программа работает только пока открыто окно; Esc или B на геймпаде закрывают процесс. Для повторного вызова запустите EXE снова. Можно добавить ярлык в игровой лаунчер. Окно можно перемещать за свободную область сверху. Размер окна фиксирован: 640 × 700 единиц WPF (Windows масштабирует его по DPI). Изменение размера и разворачивание отключены. Подсказок управления нет. Тонкий индикатор справа появляется только при переполнении списка.

## Управление

| Действие | Xbox / XInput | Клавиатура / мышь |
|---|---|---|
| Выбор устройства | Крестовина вверх/вниз, левый стик | ↑ / ↓, щелчок |
| Раздел | LB / RB, влево/вправо | ← / →, кнопки разделов |
| Применить | A | Enter, один щелчок в «Звуке» / «Мониторах» |
| Назад / закрыть | B | Esc, Alt+F4 закрывает окно |
| Список в «Программах» | X | X, кнопки «Запущенные» / «Для запуска» |
| Каталог запуска / сохранить редактор | Y | Y в списке / F2 в редакторе, команды внизу |
| Подробности ошибки устройства | Y | F1 |
| Обновить | Автоматически каждые 3 секунды | F5 |

Выделение строки ещё не меняет настройки. Маркер «Активно» показывает действующее устройство. Удержание A не выполняет действие повторно. Поддерживаются до четырёх подключённых XInput-контроллеров; используется первый доступный. Управление геймпадом работает, когда окно активно.

Мышь использует то же оформление выбора, что и геймпад: при наведении строка получает светлую рамку без заливки. Один щелчок сразу применяет устройство, запускает программу или открывает страницу действий. Правая кнопка мыши отключена. Команды каталога, сохранения и возврата расположены внизу. Стрелки перемещают выбор, Enter подтверждает, Esc возвращает назад. В поле ввода стрелки перемещают курсор; Esc завершает ввод. Повторный Enter или A не отключает редактирование. Стандартная пунктирная рамка фокуса отключена. Перетаскивание начинается после движения зажатой мыши за фон или строки списков; поля ввода и кнопки сохраняют своё обычное действие.

## Программы

Вкладка «Программы» содержит два отдельных списка:

Названия подразделов оформлены текстом без рамок; выбранный подраздел выделен светлым цветом. В «Запущенных» название приложения берётся из описания EXE (затем имени продукта, при отсутствии метаданных — имени файла). Заголовки окон используются только при выборе окна для переноса. Каждый экземпляр процесса остаётся отдельной строкой, чтобы завершать именно выбранный экземпляр.

- **Запущенные** — автоматически обнаруженные пользовательские приложения с окнами текущего пользователя, включая свёрнутые и зависшие. A / Enter / одиночный щелчок открывает действия. «На главный экран» переносит окно на текущий главный монитор; для нескольких окон сначала выберите нужное. «Завершить принудительно» открывает отдельное подтверждение, где первоначально выбрана «Отмена». Действие выбирается одиночным щелчком либо A / Enter.
- **Для запуска** — добавленные программы и ярлыки. A / Enter / одиночный щелчок запускает выбранную запись. Y открывает каталог с редактированием, удалением и добавлением. Путь к EXE, .lnk или .url вводится в редакторе; для EXE доступны аргументы и рабочая папка. Удаление требует подтверждения с выбранной «Отменой». B / Esc возвращает на предыдущую страницу.

Чтобы перенести игру на ТВ, сначала назначьте ТВ главным в «Мониторах», затем откройте действия игры в «Запущенных» и выберите «На главный экран». Обычное окно центрируется и по возможности сохраняет размер с учётом DPI; развёрнутое остаётся развёрнутым, свёрнутое восстанавливается. Безрамочное окно, покрывавшее исходный монитор, подстраивается под полные границы ТВ. Игра может самостоятельно выбирать экран; эксклюзивный полноэкранный режим не гарантируется. При неподтверждённом переносе показывается ошибка.

Принудительное завершение относится к одному выбранному процессу и всем его окнам. Остальные экземпляры, лаунчер и дочерние процессы автоматически не завершаются. Несохранённые данные выбранного процесса теряются. Для повышенных или защищённых приложений Windows может отказать в доступе; AudioSwitcher автоматически не повышает права.

Для системного Проводника вместо завершения процесса используется «Закрыть окна»: команда WM_CLOSE отправляется только окнам папок. Процесс explorer.exe, рабочий стол и панель задач не завершаются. Если окно не закрывается, программа сообщает об этом без принудительного завершения.

Служебные окна оболочки, системные хосты и фоновые процессы без пользовательских окон не показываются. Управление окнами, размещёнными в некоторых системных хостах (например, ApplicationFrameHost), в первой версии не поддерживается. Приложение не обязано находиться в каталоге запуска, чтобы появиться в «Запущенных».

В панелях действий B / Esc возвращает на предыдущий экран; в основном списке закрывает AudioSwitcher. LB / RB и ← / → переключают три верхних раздела. X переключает два списка программ. В каталоге A / Enter запускает выбранную программу, Y открывает редактирование, удаление и добавление. В редакторе крестовина выбирает атрибут без включения ввода, A активирует ввод; во время ввода вверх/вниз не меняют атрибут. B или Esc завершает ввод, повторный B отменяет форму. Y сохраняет; текст вводится клавиатурой. Открытие, перенос, завершение и отмена доступны с геймпада. После перехода между панелями A нужно отпустить перед новым подтверждением.

Каталог сохраняется в `%LOCALAPPDATA%\AudioSwitcher\programs.json`. EXE остаётся портативным, каталог принадлежит профилю Windows. Для переноса на другой компьютер скопируйте этот файл и при необходимости исправьте пути. При повреждённом файле или неизвестной версии сохранение блокируется; явный «Сбросить каталог» сохраняет резервную копию `.bak` рядом с исходным файлом и создаёт пустой каталог. Удаление записи не удаляет установленную программу. Для .url поддерживаются http, https, steam и com.epicgames.launcher; другие схемы отклоняются.

Интерфейс использует нейтральный фон и текстовые вкладки без подчёркивания. Выбранный раздел выделен светлым текстом. Выбранные строки и строки под курсором имеют светлую рамку без заливки. Действующее устройство имеет текстовую подпись «Активно» / «Главный». Enter, A или один щелчок применяет устройство. Заголовки вложенных страниц совпадают по положению с первым элементом списка и остаются неподвижными при прокрутке содержимого.

Запущенные программы и их окна обновляются каждые три секунды, в том числе на открытой карточке приложения и странице выбора окна. Выбор сохраняется по идентификатору окна; если оно закрыто, выбирается оставшееся окно. Если приложение полностью закрыто, интерфейс возвращается к списку запущенных программ.

Действия, подтверждения, выбор окна и редактор каталога сменяют содержимое основной области: старый список не просвечивает, отдельное окно редактора не открывается. После возврата восстанавливается выбор. Опасные команды выделены отдельно; подтверждение начинается с отмены. В списке запущенных программ показывается только название; заголовок окна добавляется для одноимённых экземпляров, статус — для зависшего приложения. Полные сведения доступны в действиях. Ошибка оставляет действие доступным для повторной попытки.

Переключатель «Запущенные» / «Для запуска» расположен над списком. Карточки устройств не растягиваются по высоте окна: лишнее место остаётся под списком, а прокрутка сохраняет целые строки.

В редакторе A активирует ввод в выбранном атрибуте, Y сохраняет, B выходит из ввода и затем возвращает назад. С мышью ввод активируется одним щелчком. Клавиатура: Enter активирует ввод, F2 сохраняет, Esc выходит из ввода и затем отменяет форму. Текст вводится клавиатурой; отдельного файлового диалога в этом дизайне нет.

Окно имеет один фиксированный размер. При переполнении прокручивается только список или поля редактора, с тонким индикатором справа при переполнении; заголовки страниц находятся вне области прокрутки. Палитра реагирует на системную высокую контрастность, текст — на настройку размера текста Windows. Размер окна при этом не изменяется.

## Поведение

- Звук переключается для системных ролей: обычные звуки, мультимедиа и связь. Приложения с собственным выбранным выходом могут потребовать отдельной настройки или перезапуска воспроизведения.
- Главный монитор выбирается среди активных экранов. Разрешения, частоты и взаимное расположение сохраняются. Изменения сохраняются в параметрах Windows после закрытия программы. При ошибке программа пытается восстановить прежнюю конфигурацию.
- В режиме дублирования экранов главный монитор может соответствовать общей группе дисплеев. Для отдельного выбора используйте «Расширить эти экраны» в Windows.
- Окно поверх обычных приложений; для игр используйте оконный режим без рамки. Эксклюзивный полноэкранный режим и защищённый рабочий стол Windows могут перекрывать окно.
- Программа сохраняет только пользовательский каталог запуска и не устанавливает службы. Самодостаточный EXE распаковывает встроенные нативные компоненты .NET в системный временный каталог при первом запуске.
- Для установки аудиовыхода используется недокументированный интерфейс Windows `IPolicyConfig`; совместимость с будущими версиями Windows требует проверки.

## Сборка и проверки

Требуется .NET SDK 10 на Windows. Сторонних NuGet-пакетов нет.

```powershell
./build.ps1
```

Автоматические проверки — отдельная консольная программа, завершающаяся с кодом 1 при ошибке:

```powershell
dotnet run --project tests/AudioSwitcher.Checks
dotnet run --project tests/AudioSwitcher.CatalogChecks
```

Проверка интерфейса готового EXE (открывает окно, проверяет разделы, снимает изображение и закрывает по Esc):

```powershell
./tests/ui-smoke.ps1 -ExePath ./artifacts/portable/win-x64/AudioSwitcher.exe
```

Проверка реальных устройств с временным переключением и восстановлением исходных настроек:

```powershell
dotnet run --project tests/AudioSwitcher.PlatformChecks -- --switch-and-restore
```

Без `--switch-and-restore` проверка только перечисляет устройства и проверяет отказ при выборе несуществующего устройства. Для проверки переключения нужны минимум два аудиовыхода и два активных монитора. Среды с ограничением доступа к видеодрайверу, включая некоторые песочницы, не подходят для проверки смены главного монитора.

Регрессионная проверка окна: измеряет конец списка при двух размерах окна и проверяет перемещение окна после первого подтверждения смены главного монитора в обоих направлениях. Исходный главный монитор восстанавливается:

```powershell
dotnet run --project tests/AudioSwitcher.WindowChecks -- --switch-and-restore
```

Без `--switch-and-restore` выполняются только проверки списка. Проверка использует ту же осведомлённость PerMonitorV2 о масштабе, что и портативный EXE.

Изолированные проверки нового раздела: запускают и завершают только собственные тестовые процессы, проверяют зависание, несколько экземпляров и открытие EXE/.lnk. Дополнительный флаг перемещает только тестовые окна между подключёнными мониторами; главный монитор и параметры системы не меняет. Для Windows-проверок нужен доступ к интерактивному рабочему столу.

```powershell
dotnet run --project tests/AudioSwitcher.ProgramChecks --configuration Release
dotnet run --project tests/AudioSwitcher.ProgramChecks --configuration Release -- --move-fixture
```

Версия 1.3.2 устраняет верхний зазор при прокрутке до конца: высота строк подстраивается под область списка, а прокрутка идёт по целым строкам. Первая видимая строка начинается у верхней границы при любом положении списка. Если очень длинный текст делает строку выше всей области списка, внутри неё доступна плавная прокрутка. Проверки окна включают сценарий из скриншотов, повторные проходы при четырёх размерах окна и доступность нижней части длинной строки.

Сравнительные снимки после прокрутки до конца и возврата вверх:

```powershell
./tests/ui-smoke.ps1 -ExePath ./artifacts/portable/win-x64/AudioSwitcher.exe -ScrollComparison
```

Диагностика только перечисляет устройства и не меняет настройки:

```powershell
./AudioSwitcher.exe --diagnostics ./devices.json
```

Windows API: [ChangeDisplaySettingsEx](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-changedisplaysettingsexw), [Core Audio](https://learn.microsoft.com/en-us/windows/win32/coreaudio/mmdevice-api), [XInput](https://learn.microsoft.com/en-us/windows/win32/xinput/getting-started-with-xinput).
