# AudioSwitcher

AudioSwitcher — портативная утилита для Windows 10/11, которой удобно управлять с телевизора при помощи геймпада.

Программа позволяет быстро переключать звук и главный монитор, запускать приложения и управлять открытыми окнами без использования стандартных меню Windows.

## Возможности

- Переключение устройства вывода звука.
- Выбор главного монитора.
- Просмотр запущенных приложений.
- Перемещение окна приложения на главный экран.
- Закрытие приложений.
- Запуск программ, ярлыков и ссылок из собственного каталога.
- Добавление, редактирование и удаление записей каталога.
- Настройка поведения после переноса окна:
  - перейти в приложение и закрыть AudioSwitcher;
  - оставить AudioSwitcher открытым и активным.
- Автоматическое обновление списков устройств, приложений и окон.

## Запуск

Установка не требуется. Запустите:

`AudioSwitcher.exe`

Размер окна фиксирован. Программа работает, пока её окно открыто.

## Управление

### Геймпад

- Крестовина или левый стик — перемещение.
- A — выбор или подтверждение.
- B — назад или закрыть AudioSwitcher.
- LB / RB — переключение разделов.
- X — переключение списков «Запущенные» и «Для запуска».
- Y — каталог программ или сохранение формы.

### Клавиатура

- Стрелки — перемещение.
- Enter — выбор.
- Esc — назад.
- F2 — сохранение формы.
- F5 — обновление.

## Хранение данных

Пользовательские данные находятся в:

`%LOCALAPPDATA%\AudioSwitcher`

- `programs.json` — каталог программ.
- `settings.json` — настройки AudioSwitcher.
