# AudioSwitcher

AudioSwitcher — портативная утилита для управления звуком, мониторами и приложениями в Windows 10/11 с клавиатуры или геймпада.

## Возможности

- Переключение устройства вывода звука.
- Выбор главного монитора.
- Просмотр и закрытие запущенных приложений.
- Перемещение окон на главный экран.
- Запуск программ, ярлыков и ссылок из собственного каталога.
- Добавление, редактирование и удаление записей каталога.
- Автоматическое обнаружение игр из `E:\Games` по файлу `audioswitcher.game.json`.
- Автоматическое обновление списков устройств, приложений и окон.

## Сборка

Требуется .NET 10 SDK.

```powershell
.\build.ps1
```

Готовый портативный файл будет создан в `artifacts\portable\win-x64\AudioSwitcher.exe`.
